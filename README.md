📌 Sobre o Projeto

O **Torre Mare** foi desenvolvido para facilitar a administração de empreendimentos comerciais, reunindo em uma única plataforma as rotinas de gestão financeira, contratos, locações, salas, clientes e indicadores.

O objetivo é reduzir processos manuais, melhorar o controle das informações e oferecer uma visão completa da operação em tempo real.

---

# ✨ Funcionalidades

- 🏢 Gestão de Salas Comerciais
- 👥 Cadastro de Empresas e Locatários
- 📑 Gestão de Contratos
- 💰 Controle de Mensalidades
- 💳 Gestão Financeira
- 📄 Emissão de Cobranças
- 📅 Controle de Vencimentos
- 📈 Dashboard Gerencial
- 📊 Indicadores Financeiros
- 📂 Gestão de Documentos
- 🔔 Alertas de Vencimentos
- 🔐 Controle de Usuários e Permissões
